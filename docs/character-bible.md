מקרא מקשים (ברירת מחדל חדשה): **L** = מהלך מיוחד 1 (או ↓↘→+J) · **→+L** = מיוחד 2 (או ↓↙←+I) · **↓+L** = מיוחד 3 (או →↓↘+K) · **Hype** = L+Space כשמד ההייפ מלא · **בנאליטי** = בחלון "גמור אותו!": אגרוף = בנאליטי 1, בעיטה = בנאליטי 2, מיוחד = הפתעה.
